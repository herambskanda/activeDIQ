- Corpus `sd.read.jsonl` is GENERATED by `internal/directory/sd/testdata/gen_corpus.py` (independent byte builder, asserts the spec's V01 hex). Edit the script, rerun with `python3 -I`, then `go run ./tools/fitness/corpus -update-lock`.
- Decode order matters for the spec vectors: phase A bounds (offset, AclSize, SID extent) -> phase B overlap -> phase C contents. Overlap before content parsing, else SD-23 reports a SID error.
- `AclSize` past the buffer is `sd.truncated` (SD-24 amended); `acl.size_out_of_range` only for size < 8.
- SELF (S-1-5-10) = the *object's* SID, not the principal's; keep it a separate `WithObjectSID`. An unresolved SELF allow must not hide a definite grant.
- `sid.FromBytes` demands exact length: slice by 8+4n first. Zero-subauth SIDs are unrepresentable -> bad_subauth_count.
- Pre-existing red on main: `internal/platform/operation` build (LiveFacts/PinnedFacts), `tools/fitness/stack` F2 on fleet/dial, `fitness-corpus` dn undeclared.
