# the package can reach (sockets, processes, files, directory protocols) in the commit message.
# One import path per line; `path/...` allows a subtree.

# Reviewed in T-0688 (ruling 2: knowledge/development/decisions/agent-host-fitness-rulings.md).
# Rule: exact paths, except the `internal/` subtrees of grpc and protobuf, which our code cannot import
# and which change with every release. No public subtree is allowed, so a new grpc/x-net/x-sys package
# (credentials/alts, xds, oauth, x/net/proxy, x/sys/windows/registry ...) fails until reviewed.
