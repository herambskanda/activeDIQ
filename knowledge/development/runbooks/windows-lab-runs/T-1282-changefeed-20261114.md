# T-1282 — ChangeFeed on the Windows lab DC (2026-11-14)

Tests: `internal/connector/ad/dirsync_windows_lab_test.go`, `internal/connector/read/feed_windows_lab_test.go`
(tags `lab windowslab`). Run under `lab/windows/bin/with-dc1-lock`; from a worktree set `WIN_LAB_ENV`,
`WIN_LAB_CA` to the main checkout's `lab/windows/` files and export `WIN_LAB_DC_ADDR` (read from the env
file; never printed). Test OUs are created under `OU=Managed` and removed by subtree delete.

## Observations (dc1, Windows Server 2025, Recycle Bin on)

| AC | Observation |
| --- | --- |
| 1 | A truncated cookie: LDAP result **2 (protocolError)**, diagnostic `0000203D: … Error processing control`. A garbage cookie: result **12 (unavailableCriticalExtension)**, diagnostic `00000057`. So `0000203D` is the **diagnostic text**, not the result code, and it is not "unwilling" (53). `cookieRejection` classifies on result 2 or 12, which covers both; the handler answers STALE_COOKIE / SERVER_REJECTED before any batch. A cookie with only its last bytes flipped is **accepted** by the DC (no validation of the tail), so provider_state corruption is not always detectable. |
| 2 | 1,500 new objects: the cycle spans 2–3 responses (`MoreResults` true on all but the last; 1000-object cap). Resuming from every mid-cycle cookie gives exactly the undelivered remainder, no duplicates, none lost. Through the handler: every batch but the last has `cycle_complete=false`, a cookie_after, and issued_at = cycle start; the held final batch is complete with issued_at ≥ it (CC-FEED-21). |
| 3 | The non-administrator connector identity (svc-activediq) **sees** the tombstone after a prime. With the Recycle Bin on, a just-deleted object is `DELETED` (isDeleted only, not isRecycled), never RECYCLED (T-1270). The tombstone entry's DN is empty in the decoded change (the DC did not supply one to this identity); consumers key on GUID. |
