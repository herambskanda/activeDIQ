- 2026-10-02 · factory · **ADR-0005 ratified** (operation pipeline and audit trail, technical; notice D-0015, CEO may veto). Every write, configuration writes included (Store Actions), is an EP-3 Action: Plan/Apply/Verify/Inverse or a declared Irreversible. A plan-digest-bound step token is the only key to a write. Operation/item/step state machines live in a CI-compared `transitions` block, with a `no_change` outcome. Idempotency works at three levels, with LDAP conditional modify. One DC is pinned per naming context, and pins stay out of `plan_hash`. Fenced claims, reconciliation and a sweeper run on `ManagedTx` jobs. Authorisation is re-checked live at Plan and at Apply for every DM-35 root kind, Entra and `include_correlated` included, and fails closed on `unknown`. EP-4 gate with kernel holds; the kernel enforces a 30-day two-way separation-of-duties window (customer-visible). The audit chain is built at commit through the `store` BeforeCommit hook into audit-owned tables. It carries Ed25519 checkpoints with key windows, SIEM/export anchoring, and an offline verifier that reports UNANCHORED without a trust root. Personal values are erasable through salted HMAC commitments. Rule 13 fixes the kernel import DAG (leaves `authority`, `operation/step`). Enforced by fitness-operation O1–O9 and fitness-audit A1–A9 (T-0154). Follow-ons: T-0153, T-0155, T-0037, T-0084, T-0088, T-0065. (knowledge/development/decisions/0005-operation-pipeline-and-audit-trail.md)
- 2026-10-02 · factory · **ADR-0004 ratified** (public API contract, technical; notice D-0014, CEO may veto). One OpenAPI 3.1 contract, one file per tag under `api/openapi/`, bundled. `tools/gen/api` emits every Go contract type, json/v2 `UnmarshalJSONFrom` decoders, validators and per-tag `Handlers`/`Bind` (EP-2). Third-party Go generators are Rejected because oapi-codegen's union and map templates are v1 JSON. The router is stdlib `ServeMux` in `apihost.Build`, with injected `Ports` and one fixed middleware chain. Strict JSON: a jsontext validate pass, then `secretjson.Decode` for every body, then the buffer is zeroed and secrets destroyed for secret operations. Exactly one `x-permission` per operation (`anonymous`/`authenticated` only via `policy.yaml`). One `/api/v1` that only grows, with preview/stable stability, no ManageEngine URL facade and no metering. The console uses the generated client (openapi-typescript + openapi-fetch) only. Enforced by `fitness-api` A1–A14 (T-0148, T-0149). Follow-ons: T-0147, T-0150, T-0151, and T-0152 (deprecation window, CEO before GA). (knowledge/development/decisions/0004-public-api-contract-openapi-first.md)
